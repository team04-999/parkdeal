# 데이터

## 무엇을 쓰나

| 데이터 | 내용 | 예 |
|---|---|---|
| 가게 | 이름, 업종, 좌표, 업종별 예상 체류 시간 | 필앤필버거 강남본점 · 햄버거 · 90분 |
| 가게 주차 혜택 | 혜택 종류, 무료 시간, 조건(구매·식사 금액 등), 연결된 주차장 | 이용 시 아크플레이스 2시간 무료 |
| 주차장 | 이름, 좌표, 대표 요금 규칙 | 최초 30분 6,000원, 이후 60분당 6,000원, 일 최대 60,000원 |

범위는 서울 지하철 2호선 역 주변이다.

## 출처

**네이버 지도**의 가게 정보(주차 안내)를 2026년 11월에 정리했다.

- 원문(가게 소개글, 주차 안내 문구, 전화번호)은 저장소와 앱 어디에도 넣지 않는다
- 원문에서 뽑은 **구조화한 값만** 쓴다: 무료 분, 요금 숫자, 좌표, 주차장 이름
- 앱 화면 아래에 "정보 출처: 네이버 지도"를 표시하고, 서버 응답에는 가게마다 네이버 지도 장소 링크를 함께 둔다

## 어떻게 받나

```
앱 ──▶ 주차 데이터 서버 (parkdeal-api.daeuk.cloud, 읽기 전용)
 │        실패하면
 ├──▶ 마지막으로 받은 응답 (기기 저장)
 │        없으면
 └──▶ 앱에 넣은 데모 목적지 응답 (app/src/main/assets/api-snapshot)
```

- 서버는 목적지 주변 가게·혜택·주차장만 내준다. 추천 계산(실제 낼 돈 + 걷는 거리)은 앱의 `core` 가 한다
- 시연장 인터넷이 끊겨도 데모 목적지는 동작하도록 응답을 앱에 넣어 두었다. `scripts/snapshot_api.py` 로 만든다
- 서버 코드는 별도 비공개 저장소다. 응답 형식은 `core/src/main/kotlin/com/parkdeal/core/api/ApiModels.kt` 에 있다

## 한계

- 혜택과 요금은 수집 시점 값이다. 가게 사정으로 바뀔 수 있어 화면의 금액은 "약"으로 안내한다
- 주차장 요금 정보가 없으면 "요금 확인 필요"로 표시하고 추천 순위에서 뒤로 보낸다
- 도보 거리는 직선거리 × 1.2 로 어림한다
