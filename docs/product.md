# ParkDeal 기획서

공모전 접수양식 **02 앱 프로젝트 소개**의 원문이다. 이 문서를 고친 다음 제출용 DOCX에 옮겨 붙인다.
항목 번호와 순서는 양식을 따른다. 양식 규칙상 이 장에는 이름, 연락처, 이메일, 소속을 쓰지 않는다.

> 앱명은 아직 정하지 않았다. 이 문서에서는 가칭 **ParkDeal**을 쓴다.

---

## 1. 앱 한 줄 소개

목적지를 정하면 주변 주차장 요금과 가게 무료 주차 혜택을 비교해 가장 싼 곳으로 안내하고, P단에 세운 순간부터 출차할 때까지 무료 시간과 요금을 음성으로 챙겨 주는 차량용 주차 앱입니다.

## 2. 기획 배경

낯선 동네에 차를 몰고 갈 때 운전자는 세 번 곤란해집니다.

- **도착 전**: 목적지 근처에 주차장이 여러 곳이어도 요금 체계(최초 30분, 10분당, 일 최대)가 제각각이라 체류 시간 기준 실제 금액을 비교하기 어렵습니다. 식당이나 카페가 제공하는 무료 주차 혜택은 가게 안내문이나 리뷰에 흩어져 있어 운전 중에는 찾을 수 없습니다.
- **주차 중**: 2시간 무료를 받아도 언제 세웠는지 기억하지 못해 무료 시간을 넘기고 추가 요금을 냅니다.
- **출차할 때**: 영수증 인증이나 주차 등록을 잊은 채 출구에 와서야 알게 됩니다.

휴대폰 지도 앱은 주차장 위치는 알려 주지만 "내가 몇 시간 머물면 어디가 가장 싼지"와 "지금 차가 서 있는 동안 남은 무료 시간"은 알려 주지 못합니다. 두 질문 모두 **목적지, 체류 시간, 주차 시작 시각**을 알아야 답할 수 있는데, 이 정보는 휴대폰보다 차량이 정확하게 알고 있습니다.

## 3. 앱 주요 기능 및 차량 특화 요소

| 기능 | 하는 일 | 차량이라서 가능한 점 |
|---|---|---|
| 목적지 주변 주차 비교 | 내비 목적지 주변의 공영·민영·건물 주차장과 가게 무료 주차 혜택을 모아, 예상 체류 시간 기준 실제 요금과 도보 시간으로 순위를 매깁니다 | 순정 내비에 설정한 목적지를 **NaviHelper SDK**로 받아 오므로 운전자가 다시 입력하지 않습니다 |
| 음성 추천과 경유 안내 | 1순위를 한 문장으로 읽어 줍니다. 예: "OO식당은 △△ 주차장에 세우면 2시간 무료예요. 그쪽으로 안내할까요?" 수락하면 주차장을 순정 내비 목적지로 보냅니다 | 주행 중에는 화면을 보지 않도록 **TextToSpeech SDK**로 안내하고, 경로 안내는 **NaviHelper SDK**로 순정 내비에 맡깁니다 |
| 주차 자동 기록 | 기어가 P로 바뀌면 주차장, 시각, 무료 시간을 기록합니다. 버튼을 누를 필요가 없습니다 | **Vehicle SDK**의 기어 변경 이벤트(`GearSelectionListener`)로 시작합니다 |
| 무료 시간 종료 알림 | 무료 시간 15분 전에 알림과 음성으로 알려 줍니다 | 앱을 닫아도 포그라운드 서비스가 기어와 시간을 계속 봅니다 |
| 출차 확인 | P에서 D/R로 바뀌면 지금까지 요금과 챙길 것(영수증 인증 등)을 음성으로 알려 줍니다 | 출차 순간을 기어로 정확히 압니다 |

정리하면 ParkDeal은 **도착 전(비교·안내) → 주차 중(무료 시간 관리) → 출차(요금 확인)** 의 흐름을 차량 데이터로 이어 붙입니다. 주행 중에는 화면 대신 음성과 알림으로만 상호작용합니다.

## 4. 주요 사용 시나리오

**상황**: 운전자가 건대입구역 근처 식당에서 2시간 동안 약속이 있습니다.

1. 순정 내비에 식당을 목적지로 설정하고 출발합니다. ParkDeal은 NaviHelper로 목적지를 받아 주변 주차장과 무료 혜택을 계산합니다.
2. 앱이 음성으로 말합니다. "OO식당은 이마트 자양점에 세우고 이용하면 2시간 무료예요. 그쪽으로 안내할까요?" 같은 2시간이라도 역 앞 건물 주차장에 세우면 8,000~12,000원이 듭니다(2026-11-07 현장 요금 기준).
3. 운전자가 수락하면 경로가 해당 주차장으로 바뀝니다. 원래 목적지인 식당은 기억해 둡니다.
4. 주차장에 도착해 P단에 넣으면 주차 기록이 자동으로 시작됩니다.
5. 1시간 45분이 지나면 "무료 주차가 15분 남았어요"라는 알림과 음성이 나옵니다.
6. 출발하려고 D단에 넣으면 "주차 2시간 5분, 무료 2시간을 넘겨 추가 요금이 있을 수 있어요"처럼 요금과 확인할 것을 알려 줍니다.

**다른 경우**: 가게 혜택보다 근처 공영주차장이 더 싸면 그쪽을 1순위로 추천하고 이유를 함께 말합니다. 예: "가게 혜택(1시간 무료)보다 화양동 공영주차장이 1,200원 더 싸요."

## 5. 개발 계획

Pleos Connect 환경에서 Kotlin 기반 차량용 Android 앱(minSdk 28)으로 개발합니다. 공개된 Pleos Playground SDK만 사용하고, SDK마다 핵심 기능 하나를 맡깁니다.

| SDK | 쓰는 곳 | 상태 |
|---|---|---|
| Vehicle | 기어 P/D/R 변경으로 주차 시작과 출차 판단 | 프로토타입 에뮬레이터 검증 완료 |
| NaviHelper | 순정 내비 목적지 받기, 추천 주차장을 목적지로 보내기 | 프로토타입 에뮬레이터 검증 완료 |
| TextToSpeech | 추천, 무료 종료, 출차 안내 음성 | 프로토타입 에뮬레이터 검증 완료 |
| SpeechToText | "안내해 줘" 같은 음성 응답으로 추천 수락 | 2차 PT 전 구현 예정 |

**구조**

- `core`: 요금 계산, 추천 순위, 주차 세션 상태. 안드로이드에 의존하지 않는 Kotlin 모듈이라 JVM 단위 테스트로 검증합니다. 기어 입력은 인터페이스(`GearSource`)로 분리해 테스트에서 P → D 전환을 흉내 냅니다.
- `app`: Pleos SDK 연결, 포그라운드 서비스, 화면.
- 서버: 주차장 요금과 가게 혜택 데이터를 제공하는 읽기 전용 API(NestJS + PostgreSQL). 서울시 공영주차장 공공데이터를 기본으로 하고, 민영·건물 주차장 요금과 가게 무료 혜택은 직접 확인한 값을 출처와 확인일과 함께 저장합니다.

**주행 중 화면 정책**: 주행 중에는 화면 조작 없이 음성과 알림만 씁니다. 목록과 지도 화면은 정차 중에 봅니다.

**일정**

- 1차 제출(11/15): 프로토타입 기능을 정리한 소스, release APK, 시연 영상
- 2차 PT(12/3–4): 서버 데이터 연동, STT 음성 수락, 시연 지역(건대입구역) 데이터 정비. 에뮬레이터로 위 시나리오를 처음부터 끝까지 시연

## 6. 기대효과 및 발전 가능성

**타깃 고객**

- 약속, 외식, 쇼핑으로 낯선 상권에 차를 몰고 가는 운전자
- 출장이나 외근이 잦아 주차비를 자주 내는 직장인
- 병원, 학원처럼 정해진 시간 머무는 곳을 정기적으로 방문하는 운전자

**사용자가 얻는 것**: 같은 시간을 머물러도 덜 내는 주차비, 주차장을 찾아 도는 시간 감소, 무료 시간 초과로 내는 추가 요금 방지.

**목표 지표** (가정): 서비스 지역 1곳에서 초기 MAU 1,000명, 서울 주요 상권 확대 후 10,000명. 월간 유지율 40%. 주차는 외출할 때마다 생기는 일이라 반복 사용이 많고, P단 자동 기록은 앱을 열지 않아도 동작해 사용이 끊기지 않습니다.

**확대 계획**

1. 상권 단위로 지역을 넓힙니다. 데이터 수집과 검수 절차를 자동화합니다.
2. 가게와 제휴해 무료 주차 혜택을 직접 등록받습니다. 가게는 손님을 모으고 운전자는 혜택을 얻습니다.
3. 실시간 주차 가능 대수(공공데이터)를 추천에 반영합니다.
4. 주차 예약과 결제, 법규상 가능한 단시간 정차 구역 안내로 넓힙니다.
